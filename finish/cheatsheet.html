Ripple trim — grow or shrink a clip, timeline follows

  1. T enter Trim Mode (in Normal mode the same keys leave a gap)
  2. V grab the nearest edit point
  3. U cycle which side you're trimming: clip-start / clip-end / both (roll)
  4. , . trim one frame left / right — the timeline shifts to match
  5. ⇧, ⇧. same, five frames at a time
  6. C back to Normal (pointer) mode
With start or end selected it ripples (timeline shifts). With both sides (roll) the cut moves, timeline length stays. Big jumps: park the playhead where the edit should land, then A/D below.
