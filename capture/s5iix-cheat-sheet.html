LUMIX S5IIx Cheat Sheet

Build each recipe with the dial position shown on its card, then save it to its slot. After that the C dial is all you touch.

Saving: configure the camera, then Setup (wrench) → Setting → Save to Custom Mode → pick the slot. Changes made while shooting in a C mode are temporary until you re-save over the slot.
Slot layout: C1 SSD video  ·  C2 long-record video (already saved)  ·  C3-1 street  ·  C3-2 birds  ·  C3-3 landscape

C1 Best Video → SSD BUILD ON MOVIE

SSD prepSetup → Card/File → USB-SSD → ON, then USB-SSD Format in the same menu. SSD max 2TB, 10Gbps USB, short cable. SSD unlocks ProRes at full resolution and ALL-I 800Mbps.
FormatRec. File Format Apple ProRes, quality ProRes 422 HQ. 5.8K (up to 30p) for maximum detail, C4K when you want 50/60p.
ColorPhoto Style V-Log, 10-bit. Turn on V-Log View Assist so the monitor shows a graded image.
ExposureManual. Shutter at 1/(2× frame rate): 1/50 for 24/25p, 1/100 for 50p. ND filter outdoors to hold that shutter.
ISODual native in V-Log: 640 base, jump straight to 4000 in low light. Avoid the values between them.
WB / AFWhite balance set manually per scene, never AWB mid-clip. AFC with human detection is reliable; MF for locked-off shots. E-Stabilization OFF on gimbal or tripod.

C3-1 Street · Everyday · Family BUILD ON M

Exposure1/250s, aperture at the lens's wide end (f/1.8–2.8 prime, f/4 zoom). M + Auto ISO because this body has no minimum shutter speed for Auto ISO; A mode drops to blur territory indoors.
ISOAUTO, limits 100–6400. Exposure comp button still works in M + Auto ISO.Photo → Image Quality → ISO Sensitivity (Photo)
FocusLever to AFC. Detection ON, subject HUMAN, area Full Area; joystick picks between people.Photo → Focus → AF Detection Setting / Detecting Subject
DriveDrive dial to Burst I, set to H (mechanical, ~7–9 fps).Photo → Others (Photo) → Burst Shot Setting
ShutterMECH. Electronic bands under indoor LED light.Photo → Others (Photo) → Shutter Type
FilesRAW+FINE, size L, Photo Style Standard, AWB. Stabilizer Normal.

C3-2 Birds BUILD ON M

Exposure1/2000s in flight, 1/500s perched. Aperture wide open. Noise is recoverable, wing blur isn't.
ISOAUTO, limits 100–12800.
FocusAFC, subject ANIMAL, target parts EYE. Area Full Area in flight, 1-Area perched. Animal eye AF needs S5IIx firmware 2.0+.
DriveDrive dial to Burst II, set to SH PRE: 30 fps electronic, and it buffers up to 1.5s from half-press. Half-press while tracking, full press after the moment happens. Keep Burst I on H (mechanical) as the fallback under artificial light.
ShutterSH forces electronic; fine in daylight. Fast UHS-II card recommended, the buffer fills quickly at 30 fps.
FilesRAW+FINE, size L. Stabilizer Normal, lens OIS on.

C3-3 Landscape · Architecture BUILD ON A

ExposureAperture f/5.6–f/8 (sharpest range), f/11 only when depth demands it. Diffraction softens past f/11.
ISOFixed 100. No Auto.
FocusLever to AFS, area 1-Area, placed a third into the scene. MF + peaking for tripod work.
DriveDrive dial to self-timer, 2s handheld. For maximum detail: drive dial to High Resolution mode (96MP). Handheld High-Res ON off-tripod; OFF on a tripod, where exposures up to 8s are allowed.
ShutterELEC. Zero vibration, and nothing moves fast enough to skew.
FilesRAW+FINE, AWB (RAW keeps WB editable). Stabilizer OFF on tripod, Normal handheld. Turn on grid + level gauge for verticals.
C3 slots: turn the dial to C3, press MENU/SET, pick the numbered set; the dial remembers the last one used. Rename sets via Setup → Setting → Save to Custom Mode → Edit Title. Firmware check: Setup → Others → Firmware Version. Animal eye AF and SH PRE need S5IIx v2.0+ (Apr 2024); handheld High-Res needs v1.3+ (Oct 2023). Verified against Panasonic docs, Sep 2026.
